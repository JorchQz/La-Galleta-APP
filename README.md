# La Galleta APP

Webapp para el control de inventario de ganado y contabilidad de un rancho, criadero y compra-venta.

## Cómo trabajar en este proyecto

1. Abre una sesión de Claude Code en este repo y escribe `/maestro`.
2. El Maestro lee el estado (`docs/estado/`), te dice dónde vamos y reparte el trabajo entre los agentes.
3. Al terminar, el Maestro actualiza el estado y hace commit, para que la otra persona continúe desde ahí.

- Estado actual: [`docs/estado/ESTADO.md`](docs/estado/ESTADO.md)
- Tareas: [`docs/estado/TAREAS.md`](docs/estado/TAREAS.md)
- Decisiones: [`docs/estado/DECISIONES.md`](docs/estado/DECISIONES.md)
- Preguntas abiertas para el dueño: [`docs/negocio/PREGUNTAS.md`](docs/negocio/PREGUNTAS.md)

# Glosario

> Versión 1 (2026-10-16). Términos de **práctica general** en la ganadería bovina de México. Ningún término está confirmado todavía por el dueño; el uso local (región Colotlán, Jal., *por confirmar*) puede variar. Ver `PREGUNTAS.md`.

## Giros del negocio

| Término | Definición |
|---|---|
| Giro | Línea de negocio a la que pertenece un animal o un gasto: **Rancho**, **Criadero** o **Compra-venta**. |
| Rancho | Ganado propio en pastoreo o engorda hasta su venta. |
| Criadero | Reproducción: vientres, sementales y sus crías hasta el destete. |
| Compra-venta | Ganado que se compra para revender en poco tiempo (días o semanas), con poca o ninguna engorda. También se le dice "acopio" o "negocio". |
| Traspaso | Cambio de un animal de un giro a otro (p. ej. cría del criadero que pasa a engorda en el rancho) o de una ubicación a otra. No es compra ni venta. |

## Identificación

| Término | Definición |
|---|---|
| Arete SINIIGA | Arete oficial amarillo con número único nacional de 10 dígitos (identificador de por vida). Requisito para movilizar y vender. |
| Arete interno / de manejo | Arete o número propio del rancho, más corto, para uso diario. |
| Fierro | Marca a fuego (o en frío) registrada que acredita la propiedad. Un dueño puede tener uno o varios. |
| Señal / seña | Corte en la oreja usado como marca de propiedad complementaria. |
| UPP | Unidad de Producción Pecuaria: el predio/rancho registrado en el Padrón Ganadero Nacional. Tiene clave única. |
| PSG | Prestador de Servicios Ganaderos: registro para quien no produce sino que comercia, engorda en corral o acopia ganado. |

## Categorías de animal (bovino)

| Término | Definición usual |
|---|---|
| Becerro / becerra | Cría macho / hembra, desde nacimiento hasta destete (aprox. 6–8 meses). |
| Destete | Separación de la cría de la madre; marca el paso de becerro a la siguiente etapa. |
| Novillo | Macho joven castrado (o no) destinado a engorda o venta. |
| Torete | Macho joven entero, no castrado. |
| Vaquilla (vaquillona) | Hembra joven que todavía no ha parido. |
| Vaca | Hembra que ya parió al menos una vez. |
| Vientre | Hembra destinada a reproducción (vaquilla de reemplazo o vaca). |
| Toro / semental | Macho adulto entero usado para reproducción. |
| Vaca de desecho | Vaca que sale del criadero por edad, falla reproductiva o problema; se vende. |

## Operación y pesaje

| Término | Definición |
|---|---|
| Lote | Grupo de animales que se manejan, compran o venden juntos. |
| Potrero | Terreno cercado de pastoreo. |
| Corral | Espacio cerrado para manejo, engorda intensiva o embarque. |
| Pesaje | Registro del peso de un animal (o del lote completo en báscula). |
| Peso en pie | Peso del animal vivo. Es la base de casi toda compra-venta. |
| GDP | Ganancia Diaria de Peso: (peso final − peso inicial) / días. |
| Merma | Pérdida de peso por ayuno, transporte o estrés entre la compra y el pesaje o entre el pesaje y la venta. Se negocia (p. ej. 3 %). |
| Precio por kilo | Precio pactado por kg en pie. |
| Precio por cabeza | Precio pactado por animal, sin pesar. |
| Flete | Costo de transporte del ganado. |
| Comisión | Pago al intermediario/comprador ("coyote", comisionista) por animal o porcentaje. |
| Engorda | Etapa para que el animal gane peso antes de la venta (en pastoreo o en corral). |

## Reproducción (solo lo que afecta inventario)

| Término | Definición |
|---|---|
| Empadre / monta | Periodo en que el semental cubre a las vacas. |
| IA | Inseminación artificial. |
| Diagnóstico de gestación | Revisión que confirma si la vaca está cargada (preñada). |
| Parto | Nacimiento; genera un alta de inventario. |
| Aborto | Pérdida de la gestación; no genera alta. |

## Documentos y trámites

| Término | Definición |
|---|---|
| Guía de tránsito | Documento que ampara el traslado del ganado y su propiedad. Tras la SCJN (mar-2026) su carácter obligatorio estatal está en revisión; ver `NORMATIVA.md`. |
| REEMO | Registro Electrónico de Movilización: sistema donde se registra cada movimiento de ganado por arete. |
| Pase de ganado | Documento que ampara el traslado hasta la ventanilla REEMO. |
| Factura / CFDI | Comprobante fiscal digital. En venta de ganado en pie, IVA tasa 0 %. |
| AGAPES | Régimen de Actividades Agrícolas, Ganaderas, Silvícolas y Pesqueras (ISR). |
| RESICO | Régimen Simplificado de Confianza (ISR). |

## Contabilidad

| Término | Definición |
|---|---|
| Costo de adquisición | Precio pagado por el animal + flete + comisión + otros gastos de compra. |
| Costo acumulado | Costo de adquisición (o de nacimiento) + gastos que se le van sumando (alimento, sanidad, etc.). |
| Prorrateo | Repartir un gasto común entre varios animales (por cabeza, por kilo o por días). |
| Gasto directo | Se asigna a un animal/lote concreto (p. ej. medicina a un lote). |
| Gasto indirecto / general | No se asigna a un animal concreto (sueldos, luz, renta). |
| Utilidad bruta | Venta − costo acumulado de lo vendido. |
| Existencias | Animales activos en una fecha, por categoría, giro y ubicación. |
